# V1 黄金任务目录

> 状态：`APPROVED_PRODUCT_SCOPE / MILESTONE_EXECUTION_IN_PROGRESS`
>
> 用途：用 50 条个人客户端任务验证聊天、文件、账户云同步、平台模型、Token/费用、额度/积分、充值/账单、Codex 级工具、Skill、长任务和安全。版本化固定输入、原始 Prompt 和预期结果位于 `tests/v2/golden/catalog.json`；各里程碑在实现相应切片时补执行记录。

## 1. 通用要求

- 从新对话或账户历史直接开始。
- 不要求组织、项目、团队、管理员配置或用户自备 API Key。
- 默认可以使用“自动”模型，用户也能明确选择平台提供的模型。
- 文件和工具只使用当前用户、当前设备授权范围。
- 结果保留在 Conversation，并可搜索和按账户同步。
- Pi 私有 Session 不作为历史真值。
- Token 结果来自服务端统一记录；消息、对话和账户聚合分开断言。
- 费用结果来自服务端价格快照、ChargeRecord 和不可变账本；客户端状态不作为资金真值。
- 50 条核心任务必须在批准的 Windows 和 macOS 桌面基准环境执行；iOS/Android Remote 使用 [15-remote-control-contract.md](15-remote-control-contract.md) 的独立真机/主机组合矩阵，不把手机当作执行平台。
- React Renderer 只能通过类型化 Preload Bridge 使用桌面能力。

表中“硬”表示该任务必须通过，不能被 90% 总通过率抵消。

## 7. 每次里程碑执行记录

- Catalog 中固定输入、版本、原始 Prompt 和预期结果的引用。
- 使用的模型目录版本、选择模型、实际模型和 Pi 版本。
- 预期消息、同步、文件或工具行为。
- 预期 Token 分类、总数、去重键和聚合记录。
- 预期报价、价格快照、费用、抵扣、账本分录、订单/支付状态和资金幂等键。
- 确定性检查。
- 允许的非确定性范围。
- 权限预期和禁止行为。
- Windows/macOS 差异与最大时长、资源限制。
- 自动测试入口、证据路径、执行平台和人工评分。

## 8. 人工评分

文件和内容任务按正确性、完整性、可读性、可追溯性和可继续使用性五项评分。每项 1 至 5 分，总分不低于 20，且正确性不低于 4。所有“硬”任务必须通过；质量任务允许在总门槛内形成已知失败，但不得违反安全、同步隔离、Token/费用一致性或任何资金门禁。
