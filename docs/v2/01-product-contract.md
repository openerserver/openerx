# UWA 2.0 V1 产品合同

> 状态：`APPROVED_PRODUCT_SCOPE / IMPLEMENTATION_IN_PROGRESS`
>
> 合同类型：个人 AI 客户端定位、范围、原则与未来边界

## 1. 产品定义

`已确定`：V1 是一个供单个用户直接使用的个人 AI 客户端，整体体验参考 ChatGPT 和 WorkBuddy，而不是企业控制平面、团队运营系统或产品负责人工作台。

`已确认`：

> UWA 是为企业普通用户设计的个人 AI 工作客户端。用户在一个持续对话界面中调用模型、文件、工具和技能，完成问答、分析、内容生成和较长工作，并保留可搜索的个人历史与成果。

“企业普通用户”描述使用场景和用户背景，不表示 V1 必须先建设企业组织系统。

## 1.1 交付形态

`已确定`：V1 以 Windows/macOS 跨平台桌面执行主机为核心，客户端内嵌本地构建的 Web UI；同时交付 iOS/Android Remote Companion 作为手机控制面。

`已确定`：Pi、本地文件、工具、Shell、浏览器和桌面能力只在 Windows/macOS 主机运行。iOS/Android 只远程控制已配对的在线主机；Linux 主机、公开 Web 客户端和独立移动 AI 运行时不进入 V1。

`已确定`：前端使用 React + TypeScript 重写，不继续复用旧 Vue 页面体系。

`已确定`：使用 Electron 作为桌面壳，以统一 Chromium 渲染和 Node 桌面能力；React UI 由 Vite
构建并打包进应用。Browser Computer-Use 使用独立顶层操作面：默认连接用户授权的系统默认浏览器
标签页或专用窗口，安全增强模式使用隔离 Profile 的 Electron 托管 Chromium。远程网页不嵌入主
Renderer，也不能取得客户端本地能力。

`已确定`：运行于 Windows 10 以上及较新的 macOS。`已确认系统矩阵`：Windows 10 22H2/Windows 11 x64；macOS 14 及以上，支持 Apple Silicon 与 Intel x64。Windows ARM64 暂不进入 V1。

`已确认 Remote 系统矩阵`：iOS 17 及以上 arm64；Android 11 及以上 arm64-v8a。Android x86_64 仅用于模拟器测试。

## 2. 核心价值

- 打开客户端即可开始对话，不先创建组织、项目或任务。
- 既支持快速问答，也支持需要文件、工具和多步骤执行的工作。
- 用户可以停止、继续、修改、重试和重新生成。
- 对话、文件、工具结果和成果保持在同一上下文。
- 账户云同步让个人历史和成果可在 Windows 与 macOS 设备间恢复。
- 高级能力可以使用，但不要求用户理解 Agent、Session 或编排系统。
- 平台统一提供模型，用户无需准备 API Key，也可以明确选择适合自己的模型。
- Token、单价、实际费用、可用额度和账单对用户透明，余额不足时有清楚的充值与替代路径。
- 模型可以替换；Pi 版本通过稳定宿主边界升级，账户历史不随 Pi 内部 Session 或版本变化而丢失。
- 用户离开电脑后可以从手机查看、Queue、Steer、Stop、审批和审阅仍在在线桌面主机上执行的工作。

## 3. V1 产品原则

### 3.1 对话优先

客户端启动后直接进入对话。Conversation 是第一用户心智，正式 WorkItem 只在长任务需要持久执行时由系统内部创建。

### 3.2 单用户优先

V1 所有导航、设置、数据和验收围绕当前用户展开，不要求用户理解团队、组织、管理员或审批链。

### 3.3 简单任务立即响应

普通问答、改写、总结等任务在当前对话内直接流式返回，不强制进入复杂任务编排。

### 3.4 复杂任务逐步增强

只有涉及长时间执行、多个工具、文件成果或中途确认时，才展示简化进度、后台继续和恢复能力。

### 3.5 默认简单，高级可选

“自动”是默认模型项；允许用户在设置或对话顶部从 UWA 当前提供的模型目录中明确选择模型、助手和 Skill，但不能成为开始对话的前置配置。V1 不要求或允许用户配置第三方 Provider API Key。

### 3.6 权限由用户掌握

本地文件、文件夹、浏览器、Shell、MCP 或外部系统能力必须在清晰授权边界内使用，敏感动作不得静默执行。

### 3.7 历史独立于 Pi Session

Conversation、Message、Attachment 和 Artifact 是产品数据；Pi/Codex Session 只作为内部执行引用。

### 3.8 Pi 完整提供 V1 Agent Harness

V1 使用当前维护中的 Pi 包完整提供 Agent Loop、Session 管理、上下文压缩、内部重试和工具调用生命周期。V2 负责 Pi 的受控宿主、产品状态投影、权限与能力 Broker、持久化、同步、模型网关、计费和 UI。UWA 不定义替代 harness、通用 adapter 或平行执行器。

### 3.9 账户同步是 V1 能力

登录账户后的对话、消息、附件云副本、成果、模型选择和可同步个人设置进入云同步。已确认架构由云端保存账户范围真值，本地缓存用于启动、离线读取和待同步写入。设备级文件路径、权限、Cookie、Shell 历史、密钥和临时目录不跨设备继承。

### 3.10 用量对用户透明

消息、对话和账户用量页展示可获得的 Token，包括输入、缓存输入、输出、推理和总 Token；同时展示对应价格版本、实际费用和抵扣来源。额度、积分和充值余额分开呈现，所有扣减、充值、退款和调账都能回到可核对账单。

收费请求执行前必须校验可用价值并形成报价/预留；V1 默认不允许静默透支。商业规则以 [11-billing-and-commerce-contract.md](11-billing-and-commerce-contract.md) 为准。

### 3.11 手机是控制面，桌面是执行面

iOS/Android Remote Companion 只发送经过账户、设备、配对、时效和 revision 校验的产品命令。桌面 Personal App Service 把开始、Steer、Queue 和 Stop 直接映射到 Pi `prompt()`、`steer()`、`followUp()` 和 `abort()`；不在手机、Relay 或 V2 建立第二套 harness、Agent 队列或 SessionManager。完整合同见 [15-remote-control-contract.md](15-remote-control-contract.md)。

## 4. V1 必须范围

### 4.1 对话

- 新建、重命名、搜索、归档和删除对话。
- 流式回答、停止生成、重新生成和继续追问。
- 编辑上一条用户消息，并保留清晰分支或版本结果。
- Markdown、代码块、表格、引用和附件展示。
- 长对话上下文管理和明确的压缩/截断提示。

### 4.2 文件与上下文

- 拖放或选择文件。
- 查看已添加文件、解析状态和失败原因。
- 在当前对话中引用文件。
- 将常用文件和生成成果保存在个人文件区，并按账户同步支持范围生成云副本。
- 在明确授权后读取或修改整个本地文件夹，并允许用户撤销 Scope。
- 创建、编辑、预览和版本化常见文档、表格、演示文稿、PDF、图片、文本/代码和 HTML 成果。
- 不允许 Pi Host 或工具任意扫描未授权目录。

### 4.3 助手、技能与工具

- 一组经过验证的内置助手、工具和 Skill。
- 支持个人/工作区 Skill 的安装、显式或自动触发、更新、禁用、权限重置和卸载。
- 支持 Web 搜索、双后端 Browser Computer-Use、受控桌面操作、Shell/代码执行以及本地和远程 MCP。
- 工具调用状态、目标、来源、结果和错误以用户可理解方式显示。
- 敏感工具调用前请求确认；设备权限不得通过账户同步自动继承。
- 完整范围和门禁以 [10-codex-capability-baseline.md](10-codex-capability-baseline.md) 为准。

### 4.4 个人成果

- 在对话内预览生成的文档、表格、演示文稿或其他文件。
- 下载、打开、再次引用和生成新版本。
- 可以从个人文件/成果入口重新找到，而不是只能翻找聊天记录。

### 4.5 设置

- 外观、语言和基础行为。
- 平台账户、登录设备、同步状态和数据保留。
- 平台模型目录、默认模型和各对话的明确模型选择。
- 消息、对话和账户累计 Token、费用与抵扣明细。
- 个人额度、积分、充值余额、充值订单、退款和月度账单。
- Pi Host、工具、文件和网络权限。
- MCP 服务、Skill、浏览器后端/Profile、Browser Bridge 授权和 Shell Scope。
- 历史、缓存、下载和数据清理。
- 诊断信息导出，但不提供企业管理员控制台。

### 4.6 账户云同步

- 注册、登录、刷新会话、退出当前设备和退出全部设备。
- 同步状态、最后成功时间、待上传数量和失败重试可见。
- Conversation、Message、分支、附件云副本、Artifact、模型选择和可同步设置可在另一台设备恢复。
- 冲突保留版本或要求用户选择，不静默覆盖。
- 删除、导出和保留范围对本地缓存、云端真值和备份分别说明。

### 4.7 平台模型、用量与价格

- 客户端从平台模型目录读取模型名称、能力、状态、限制和当前计价方式。
- “自动”与明确选模同时存在；明确选择在当前对话中保持并同步。
- 每次运行记录用户选择模型和实际执行模型；降级或回退必须可见。
- Token 使用记录以服务端统一记录为真值，客户端不得自行修改或重复累计。
- 每次收费使用执行前冻结的价格快照，实际费用可追溯到 Token、模型和费率版本。

### 4.8 个人额度、充值与账单

- 分开显示平台额度、积分和用户充值余额，以及各自适用范围和有效期。
- 收费执行前创建报价并预留可用价值，执行后按真实用量结算并释放未用预留。
- 余额不足时不静默欠费，提供充值、切换模型或降低本次费用上限的选择。
- 充值使用正式支付渠道和服务端确认；客户端返回页不能单独证明支付成功。
- 提供消费、充值、退款、冲正和调账明细，以及可下载月度账单。
- 已入账流水不可修改或删除；错误通过冲正和新记录更正。

### 4.9 Remote Control

- 从 iOS/Android 查看和切换已配对的 Windows/macOS 主机。
- 在在线主机上开始或继续对话，查看流式状态和成果。
- 明确区分 `Steer`、`Queue` 和 `Stop`，并直接采用 Pi 原生语义。
- 回答待补充问题，允许或拒绝仍有效且未扩大桌面 Scope 的审批。
- 审阅回答、Diff、测试、终端、截图和 Artifact；从手机上传图片或文件作为账户附件。
- 通过不包含敏感正文的推送获知需要审批、完成和失败。
- 主机休眠、离线、应用退出或 Remote 关闭时不接受新执行；不提供远程唤醒或云端代跑。

## 5. V1 非目标

- 产品负责人、团队负责人或管理层工作台。
- 组织、部门、团队、成员邀请和角色体系。
- 企业审批流、预算中心、组织审计中心和策略模板。
- 团队知识库、团队成果分享和协同评论。
- 通用工作流设计器和面向用户的 DAG。
- AgentOps、多任务运营大盘和 Pi 内部运维控制台。
- 完整 IDE、代码托管或 DevOps 控制平面。
- 同时接入全部企业软件生态。
- BYOK、自定义模型 Provider 和本地模型运行入口。
- 组织预算中心、部门成本分摊、管理员代付和企业授信账期。
- 多币种钱包、积分交易/提现、税务发票平台和订阅套餐。
- 在手机端运行 Pi、Shell、浏览器自动化、MCP、Skill 脚本或桌面控制。
- 远程桌面、任意终端接管、远程唤醒、无人值守登录和主机离线执行。

## 6. Future Enterprise 方向

只有个人客户端的留存、任务成功率和安全边界得到验证后，才评估：

- 产品/团队负责人视角。
- 团队空间、共享对话、共享成果和知识库。
- 组织成员、权限、SSO 和目录同步。
- 管理员配置、审批、预算、审计和数据治理。
- 企业连接器统一安装和权限继承。
- SaaS 多租户与私有部署管理。

这些方向不是 V1 承诺，也不参与 V1 完成度计算。

## 7. 产品承诺边界

V1 可以承诺：

- 对话、文件、工具和成果形成完整个人使用闭环。
- 登录账户后，核心历史和成果可以跨 V1 支持设备同步和恢复。
- 用户能够明确选择平台模型，并看到本次和账户级 Token、费用、余额与账单。
- 用户能够安全充值；充值、扣费、退款和调账均有不可变、可核对记录。
- 文件、工具和 Skill 达到已冻结的 Codex 能力基线。
- 用户可以知道系统正在做什么、访问什么和等待什么。
- 复杂执行可以停止，并在支持范围内恢复。
- 更换模型或升级 Pi 版本不改变个人历史的业务身份。
- 用户可从已配对手机安全控制在线桌面任务，而不公开暴露桌面主机或扩大其既有权限。

V1 不应承诺：

- 已具备完整企业治理能力。
- 模型输出永远正确。
- 可以绕过文件或外部系统权限。
- 所有任务都能无人监督完成。
- 未来团队能力已经存在或兼容所有旧控制平面数据。
- 手机可以独立完成桌面本地执行、在主机离线时继续运行或远程授予新的操作系统/文件权限。
