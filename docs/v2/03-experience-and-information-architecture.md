# V1 体验与信息架构合同

> 状态：`APPROVED_PRODUCT_SCOPE / IMPLEMENTATION_IN_PROGRESS`
>
> 合同类型：ChatGPT/WorkBuddy 式个人客户端导航、桌面聊天与手机 Remote 交互边界

> 交付形态：Electron 跨平台桌面执行主机 + React/TypeScript Web Renderer + React Native iOS/Android Remote Companion

## 1. 主体验

客户端启动后的默认动作是“开始新对话”。用户不需要先选择组织、项目、任务类型、运行档位、凭证或工作流。

V1 的主界面由三部分组成：

1. 左侧：新对话、搜索、可折叠的个人项目和历史。
2. 中央：当前对话、输入框、附件、模型/助手可选项。
3. 右侧或抽屉：文件、成果预览和长任务详情，仅在需要时出现。

## 2. 主导航

`已确认`：

| 入口 | 用途 | 优先级 |
| --- | --- | --- |
| 新对话 | 立即开始聊天 | 固定首位 |
| 搜索 | 搜索对话、消息、文件和成果 | V1 |
| 个人项目 | 复用项目说明、对话归属和本机目录上下文 | V1，可选 |
| 最近对话 | 返回和继续历史 | V1 |
| 个人文件/成果 | 管理上传文件和生成成果 | V1，可作为次级页面 |
| 设置 | 账户同步、模型、用量与账单、Remote 设备、权限、数据、外观和诊断 | V1 |

不设置 Dashboard、团队空间、企业项目、Agent 控制台、审批中心或管理员中心作为 V1 主导航。个人项目是侧栏中的轻量可选入口，不影响启动后直接开始新对话。

## 3. V1 路由

| 路由 | 页面 |
| --- | --- |
| `/` 或 `/chat/new` | 新对话 |
| `/chat/:conversationId` | 历史或当前对话 |
| `/projects` | 个人项目列表 |
| `/projects/:projectId` | 项目首页、项目对话和目录状态 |
| `/projects/:projectId/chat/new` | 在指定项目中开始新对话 |
| `/search` | 个人搜索 |
| `/files` | 个人文件与成果 |
| `/assistants` | 兼容入口，重定向到设置中的助手与 Skill |
| `/settings/account` | 账户、设备、Remote 配对和云同步 |
| `/settings/models` | 平台模型目录和默认选择 |
| `/settings/usage` | Token 与费用记录 |
| `/settings/billing` | 额度、积分、充值余额、消费和月度账单 |
| `/settings/recharge` | 创建充值订单并查看支付结果 |
| `/settings/tools` | 工具、MCP、浏览器、Shell 和权限 |
| `/settings/account?section=assistants` | 个人助手与 Skill 管理 |
| `/settings/*` | 个人设置 |

React Renderer 使用应用内部路由。V1 不以公开 Web 站点作为主客户端入口，但业务路由不得依赖 Electron 私有全局对象，以便测试和未来复用。

## 4. 新对话体验

空白对话必须包含：

- 一个占主要视觉焦点的输入框。
- 文件添加入口和拖放能力。
- 3 至 6 个个人常用建议，不依赖管理员发布。
- 最近使用的模型或助手，可选显示。
- 清晰的账户与同步提示，例如“已同步”“离线，3 项待同步”或“同步失败”。

不得先展示 Provider API Key、Agent 队列、项目状态或系统治理信息。Token 和费用应在消息详情及账户用量页可发现；低余额需要提醒，但不能让钱包信息压过空白对话的主要输入区。

### 4.1 个人项目体验

- 新建项目只要求名称；项目说明和首个目录均可跳过。
- 第一个目录自动成为主目录，后续目录默认为附加目录；用户可显式更换主目录。
- 项目首页以“开始对话”和最近对话为主，目录、说明和归档设置渐进呈现。
- 项目内对话显示项目胶囊；上下文抽屉明确区分“来自项目”和“仅此对话”。
- 当前设备未连接项目目录时，项目和历史仍可查看；需要文件能力时显示“在此设备重新连接目录”。
- 移动现有对话时列出下一轮将新增或移除的项目上下文，正在运行的轮次不允许移动。

## 5. 输入框合同

输入框至少支持：

- 多行文本。
- 粘贴图片和文件。
- 拖放附件。
- 发送与停止。
- 可选的模型、助手或技能入口。
- 清楚展示当前附件和授权上下文。

文件仍在解析时，系统应显示状态并明确是否允许先发送文本。

## 6. 消息合同

每条助手消息可以包含：

- 流式文本。
- Markdown、表格、代码和引用。
- 可折叠的工具活动。
- 文件或成果卡片。
- 待确认动作。
- 可折叠的本次 Token、实际模型、价格快照和费用详情。
- 重试、复制、反馈和继续操作。

原始 Tool Call JSON、Pi Session ID 和内部事件不能作为普通消息主体。

## 7. 对话分支与编辑

用户编辑旧消息或重新生成时：

- 旧结果不得被静默覆盖。
- UI 必须允许识别当前分支或版本。
- 搜索和历史默认回到最后活跃分支。
- 分支实现不暴露 Pi Session 的内部结构。

## 8. 长任务体验

普通聊天不创建显式任务页面。只有当工作需要后台执行、多个工具或文件成果时，消息内出现简化任务卡：

- 正在准备。
- 正在读取文件。
- 正在分析。
- 正在生成成果。
- 需要你确认。
- 已完成或未完成。

用户可以离开当前对话；返回后从持久化事件恢复状态。

## 9. 文件与成果体验

- 附件在发送前可移除。
- 文件卡显示名称、类型、大小和解析状态。
- 来源引用可以打开到文件、页码、工作表或数据范围。
- 生成成果在对话中直接预览或打开侧栏。
- 成果可以下载、另存、再次引用和生成新版本。
- 文本、代码和 HTML 支持源码视图；HTML 渲染使用无桌面权限的隔离预览。
- 授权文件夹显示绝对路径、读写范围、有效期和撤销入口。
- 项目目录显示主/附加角色、继承来源和当前设备连接状态；逻辑目录可同步，绝对路径与 Grant 不同步。
- 文件或成果显示“仅本机、待同步、已同步、冲突、同步失败”状态。
- 个人文件页是辅助管理入口，不取代聊天。

## 10. 工具确认体验

已授权范围内的自动动作只进入可折叠活动与审计，不制造确认卡。需要建立 Scope 或逐次审批时，确认卡必须说明：

1. 准备使用什么能力。
2. 将读取或修改什么。
3. 是否会访问网络、控制其他应用或运行命令。
4. 授权是仅本次、当前对话还是长期。
5. 拒绝后能否继续使用降级方案。

默认选项应遵循最小权限；“始终允许”不得被视觉上诱导选择。

工具入口遵循渐进呈现：

- Web 搜索和低风险文件读取显示折叠活动与来源。
- 浏览器网页始终位于独立顶层窗口/标签页，不嵌在右侧面板；右侧面板只显示后端、精确 surface、
  control path、语义状态、按需截图证据、暂停/接管/恢复/停止。默认使用系统浏览器，用户可切换到
  隔离 Profile 的托管 Chromium；Bridge 连接、上传和提交按风险确认。
- Shell 在对话级终端面板中显示工作目录、命令、流式输出、停止和退出状态。
- 已授权读写工作区内的 Patch 和操作系统沙箱 Shell 自动执行；工作区外执行、未授予的网络或其他越界请求必须停下。
- 桌面控制显示目标应用和动作；普通交互可按当前对话和应用建立 Scope，登录、发送、购买、删除和提交逐次确认。
- MCP 服务和工具显示来源、认证状态、所需权限和断开入口。

## 11. 模型与助手选择

- 新用户使用自动模型，不需要选择。
- 用户可以在对话顶部从 UWA 平台当前提供的模型目录中明确选择。
- 模型项展示主要能力、相对速度、上下文限制和当前单位价格；不可用原因直接显示。
- 模型切换仅影响后续消息，并清楚显示变化。
- 新任务输入区和对话顶部都提供思考强度选择；只展示当前模型目录明确声明支持的等级。
- 模型与思考强度切换仅影响后续消息。对话记住两项选择并随账户同步；任何实际模型降级在消息详情显示。
- 助手和技能使用业务名称，技术 ID 放入详情。
- 模型不可用或不支持当前文件/工具时，先提示切换，不要求用户重新配置 Provider。

## 11.1 Token 与费用记录

- 每条助手消息的详情显示可获得的输入、缓存输入、输出、推理和总 Token 计数。
- 对话详情显示累计 Token 和费用；账户用量页显示按日、按模型和按对话聚合的 Token、原价、抵扣和实扣金额。
- 服务端返回的已知 Token 直接记录；缺失字段显示“暂不可得”，不得用 0 冒充。
- 重试、同步重放或客户端刷新不得重复累计同一次模型调用。
- 每笔费用展示实际模型、价格版本、计费数量、额度/积分/余额抵扣和最终金额；未知费用不得显示为 0 或“免费”。
- 收费执行前展示单位价格和报价；超过用户单次费用上限时再次确认。

## 11.2 额度、积分、充值与账单

- 设置首页或账户菜单显示可用额度、积分和充值余额；三类资产分开展示。
- 每笔额度和积分显示来源、适用范围、剩余值和有效期；即将过期有可关闭提醒。
- 余额不足卡片提供充值、切换低价/免费模型和调整本次上限，不制造“消息已发送但后台欠费”的假状态。
- 充值页先创建服务端订单，再打开受信任收银台；返回客户端后显示“确认中”，直到服务端确认成功或失败。
- 账单页按消费、充值、退款、冲正和调账筛选，并可查看稳定记录编号与下载月度明细。
- 账单不是税务发票；V1 不提供发票申请，也不使用“开发票”误导用户。

## 11.3 Skill 选择与管理

- 输入框可显式选择 Skill；系统自动匹配时，在首次实际使用处显示 Skill 名称和原因摘要。
- Skill 页面显示内置、个人和工作区 Scope，以及来源、版本、依赖、权限和平台兼容性。
- 安装、启用、更新新增权限、权限重置和卸载均有明确结果。
- Skill 的脚本、浏览器、Shell 或 MCP 行为复用同一工具确认卡，不获得旁路权限。

## 11.4 账户与同步

- 登录后在侧栏底部或设置中显示账户、当前设备和同步状态。
- 同步错误不得只显示红点；必须说明失败对象、是否会自动重试和用户可采取的动作。
- 退出设备前说明本地缓存处理方式；删除云端数据与清理本机缓存分开确认。
- 冲突页面允许保留两个版本或明确选择，不静默采用最后写入者。

## 12. 状态与错误语言

| 内部情况 | 用户文案 | 用户动作 |
| --- | --- | --- |
| 正在排队 | 正在准备 | 停止 |
| 正在执行 | 正在处理 | 停止、离开对话 |
| 需要输入 | 需要你补充 | 回复或取消 |
| 需要权限 | 需要你的允许 | 查看范围、允许或拒绝 |
| 模型失败 | 本次回答未完成 | 重试或切换模型 |
| 工具失败 | 某项操作未完成 | 查看原因、重试或继续 |
| Pi Host 中断 | 执行意外中断 | 恢复、重试或保留已有结果 |
| 同步失败 | 还有内容未同步 | 重试、查看对象或保持离线 |
| Token 记录延迟 | 本次用量稍后更新 | 稍后刷新，不重复执行任务 |
| 费用待核算 | 本次费用正在确认 | 查看已预留上限，稍后自动更新 |
| 余额不足 | 当前可用额度不足 | 充值、切换模型或降低本次上限 |
| 支付确认中 | 支付结果正在确认 | 保持页面或稍后在充值记录查看 |
| 支付失败/关闭 | 本次充值未完成 | 重试或更换支付方式，不重复入账 |
| 账单调整 | 本期有一笔退款或冲正 | 查看原记录和调整原因 |
| Remote 主机离线 | 电脑当前不可用 | 查看历史、切换主机或在电脑上线后重试 |
| Remote 命令冲突/过期 | 这项远程操作没有执行 | 刷新最新状态后重新选择 Queue 或 Steer |

V1 不向用户展示 `candidate`、`judge`、`phaseRole`、`task graph` 等内部状态。

## 13. Future Enterprise UI

团队、产品负责人、管理员、组织知识和审计页面不在 V1 路由中建立占位入口。未来如果启动，应作为独立信息架构重新设计，而不是向个人侧栏持续追加复杂菜单。

## 14. 桌面端体验

V1 桌面壳至少负责：

- 原生窗口生命周期、最小尺寸和多显示器恢复。
- 文件选择、拖放和安全的系统打开/另存为。
- 账户登录回调、安全会话存储和同步网络状态。
- 通过受信任远程收银台完成充值；支付内容使用无 Preload Bridge 的隔离窗口或系统浏览器。
- 应用菜单、可选托盘和系统通知。
- 单实例、深链接和协议唤起。
- 更新提示、安装和重启。
- 崩溃恢复和脱敏诊断。

React Renderer 只通过类型化 Bridge 请求桌面能力，不直接调用 Node、文件系统或进程 API。

## 15. 手机 Remote 体验

iOS/Android Remote Companion 不是桌面界面的缩小版。主导航固定为 `Hosts`、`Tasks`、`Inbox` 和 `Settings`：

- `Hosts` 显示已配对 Windows/macOS 主机、在线状态、版本、当前项目/工作区和撤销入口。
- `Tasks` 用于在在线主机开始/继续对话，查看流式回答、工具活动和成果。
- `Inbox` 聚合待补充、待审批、完成和失败提醒；推送通过深链接进入准确对象。
- `Settings` 管理账户、通知、设备密钥、配对、隐私和退出。

活动任务必须把三个动作清楚区分：

- `Steer`：改变正在进行的工作，直接采用 Pi `steer()` 语义。
- `Queue`：不打断当前工作，直接采用 Pi `followUp()` 语义。
- `Stop`：终止当前执行，直接采用 Pi `abort()` 语义。

手机可选择项目、开始项目对话、只读审阅目录连接状态、Diff、测试、终端、截图和 Artifact，并上传手机图片/文件作为账户附件；不能浏览任意桌面路径、重新连接项目目录、授予新文件夹 Scope、改变读写范围、操作系统权限或接管桌面画面。主机离线时只允许读取已同步历史，不显示“已排队”造成稍后意外执行。完整边界见 [15-remote-control-contract.md](15-remote-control-contract.md)。
