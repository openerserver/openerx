# 个人项目的公共合同

适用范围：Windows/macOS 桌面端、本地业务与通用同步协议。项目是轻量的对话组织与工作目录上下文，不是企业组织、成员或管理平台。

## 数据与权限

- Project 保存名称、说明、置顶和归档状态；不要求先绑定目录才能创建。
- ProjectDirectory 保存逻辑目录，ProjectDirectoryBinding 和 WorkspaceGrant 保存当前设备上的实际授权。
- 一个项目可有多个目录，仅一个主目录。不同目录独立选择只读或读写范围。
- 项目元数据可通过可选同步服务传播，绝对路径、目录句柄和权限不传播；另一设备必须重新选择目录。
- 项目对话继承项目说明与当前设备已授权目录，普通对话不能意外继承项目授权。运行中的任务不因对话移动或主目录切换而改变既有执行范围。

## 恢复与删除

目录选择与授权提交可重放，但不能创建重复授权或双主目录。设备断开只撤销当前设备的绑定；移出项目通过逻辑墓碑传播撤销。归档或删除项目不直接删除磁盘文件。

App Service 中断后，未完成执行需要到达明确恢复/失败状态，项目、目录绑定和历史记录保持可核对。迁移与回滚必须保留项目、对话归属以及设备授权关联。

## 通用远程扩展

公共 Remote 合同可暴露项目逻辑标识和目录连接状态，但不传设备路径、目录句柄或 Grant。外部控制器不能通过远程请求选择本机目录或扩大权限；任何操作仍走桌面 App Service 和 Capability Broker。具体企业控制器 UX 与移动端实现不在本仓库。

## 验证

公开测试与源码映射见 [测试说明](../TESTING.md)。正式桌面发行需要签名包的目录选择、读写、断开、重连、上下文隔离、升级保持和异常恢复证据；尚未完成的项目保留 pending 状态。可选跨设备服务与企业移动发行的部署验收另行进行。
