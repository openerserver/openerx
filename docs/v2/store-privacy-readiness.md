## 核心隐私事实

- 默认模型设置是 BYOK，使用用户选择/配置的模型服务和凭证；文本、历史、图像和工具内容可以成为模型请求。部分记忆处理及自动任务也可以调用模型。
- 模型 API 密钥和连接凭证通过 Electron safeStorage 包装的系统保护机制加密；普通会话/文件使用本机数据库及文件存储，不能宣传全部本地内容均已应用层加密。
- 会话、任务、文件资料、产物、记忆等有本机持久化；文件授权可以撤销，个人数据可以导出。
- 会话删除为逻辑标记；附件、数据库记录、导出文件不能承诺同时立即销毁。
- 搜索会向 Bing/Baidu 发送查询；浏览器访问网站和用户连接的 MCP 工具可产生第三方外联。BYOK 数据也不等于离线处理。
- 本地 DiagnosticsService 保存脱敏生命周期事件和性能指标，日志大小有界，最多导出最近 1,000 条；用户经保存对话框把诊断包写入本机。未发现应用级集中遥测或崩溃报告上传路径，不能据此担保第三方/Windows 永不采集。
- 当前商店包未预配置 OpenERX 平台 endpoint；账户、云同步、平台计费及 Remote 等不应被写作已可用的默认云服务。
- 已修正源码 UI 的“内容不会用于模型训练”绝对承诺，改为“模型数据处理以服务商政策为准”；展开说明补充任务内容可能发送给模型服务，以及保存和训练用途取决于服务商政策及账户设置。两处修正已进入 2.0.2.0 新候选包；原 2.0.1.0 包仍含旧文案，需以新包替换。

详细政策及事实源见 `store-privacy-policy-draft.md`。
