## 3. 已确认的关键细节

### 3.1 客户端形态

- V1 支持系统：Windows、macOS，已确认
- 各系统最低版本：Windows 10 22H2/Windows 11；macOS 14 Sonoma 及以上（作为“较新的 macOS”的当前具体解释）
- CPU 架构：Windows x64；macOS Apple Silicon arm64 与 Intel x64；Windows ARM64 暂不进入 V1
- 是否必须具备桌面常驻能力：不强制常驻
- 是否需要系统托盘、全局快捷键或划词唤起：V1 不做
- 是否需要语音输入和实时语音：V1 不做
- 安装包是否必须支持无管理员权限安装：Windows 支持当前用户安装；macOS 使用标准应用安装

### 3.2 数据与账户

- 对话是否默认只保存在本机：否；账户数据进入云同步，本机保存受控缓存
- 是否需要多设备同步：是，V1 必须支持 Windows 与 macOS 之间同步
- 是否需要账号注册和登录：是，使用云同步时必须登录个人账户
- 登录方式：邮箱验证码登录；手机号、第三方账号和企业 SSO 后置
- 是否允许匿名或完全离线模式：不允许匿名；网络中断时允许读取缓存和排队消息
- 历史记录默认保留多久：用户删除前一直保留；删除后 30 天回收期
- 同步范围：对话、消息、分支、附件云副本、成果、模型选择、个人 Skill 安装记录和可同步设置；设备级权限、绝对路径、浏览器 Cookie、Shell 历史、密钥和临时工作区不跨设备同步

### 3.3 模型、用量与商业账户

- 使用平台统一模型，还是用户自带 API Key：平台统一模型；V1 不提供用户自带 API Key
- 是否允许用户明确选择模型：允许，只能选择平台当前提供且账户可用的模型
- 是否支持本地模型：V1 不支持，列入未来候选方向
- V1 展示什么用量：记录和展示可获得的输入、缓存输入、输出、推理及总 Token
- V1 是否展示额度、费用或积分：是；额度、积分和充值余额分开显示，费用关联实际 Token、价格版本和抵扣明细
- V1 是否支持充值和账单：是；必须支持充值订单、支付状态、退款/冲正、消费流水和月度账单
- 服务端记账边界：使用不可变复式账本、稳定幂等键和支付对账；客户端、Runtime 和同步队列不得直接修改余额
- 账单是否等于税务发票：否；V1 不提供税务发票申请
- 订阅/月卡是否进入 V1：否；V1 采用充值和按量结算
- 商业合同详见 [11-billing-and-commerce-contract.md](11-billing-and-commerce-contract.md)

### 3.4 文件、工具和技能

- 能力基线：以 2026-08-25 核对的 Codex 桌面能力为 V1 功能与验收基线；具体矩阵见 [10-codex-capability-baseline.md](10-codex-capability-baseline.md)
- 首批支持的文件格式：PDF、DOCX、XLSX、CSV、PPTX、常见文本/代码/结构化文本、常见图片，以及 HTML 源码与隔离预览
- 是否允许授权整个本地文件夹：允许；必须显示路径、读写范围和有效期，并阻止符号链接或路径穿越绕过
- 是否支持浏览器操作：支持；使用与主 Renderer、用户日常浏览器隔离的浏览器上下文
- 是否支持 Shell/代码执行：支持；限定工作目录、流式输出、可停止，写入/网络/高风险命令受沙箱与审批约束
- 是否支持 MCP：支持本地 STDIO 与远程 Streamable HTTP，远程认证支持 Bearer/OAuth；每个服务可禁用、重连和清除授权
- 用户是否可以安装第三方 Skill：可以；支持个人和工作区 Scope、显式/自动触发、查看来源与权限、禁用、更新和卸载

### 3.5 首批成果

- 聊天文本：支持
- 在线文档：V1 支持客户端内预览和版本，不承诺多人在线协作文档
- DOCX/PDF：支持创建、预览、下载、再次引用和版本化
- XLSX/CSV：支持创建、预览、下载、再次引用和版本化
- PPTX：支持创建、预览、下载、再次引用和版本化
- 图片或其他媒体：支持图片输入、预览和平台提供的图片生成能力；V1 暂不做音视频

| 进入实施授权 | 是否现在开始重构代码 | 当前仍为“否”；你明确说“按此方案开始实施”后才进入代码阶段 |

## 4. V1 明确不做

- 产品负责人或团队负责人工作台。
- 组织架构、部门、成员和团队空间。
- 企业管理员控制台。
- 组织级助手发布、审批、预算和审计中心。
- 多租户、SSO、SCIM 和复杂私有部署治理。
- 团队知识权限继承和团队成果协作。
- 面向普通用户的 Agent Run、Session、任务图和 DAG 控制台。
- 组织预算中心、部门成本分摊、企业授信账期和管理员代付。
- 多币种钱包、积分转赠/提现、订阅套餐和税务发票平台。

这些能力可以保留清晰扩展接口，但不得占用 V1 页面和交付周期。
