# 移动端新建项目 · 2026-09-16（Asia/Shanghai）

原因：移动端原先只提供查看和选择电脑项目的入口，远程命令只支持 `project.list` 和在已有项目中启动任务，没有项目创建命令。UWA 中央服务的命令校验也未接受项目创建。

本次补齐 openerx 与 UWA 当前移动端的创建流程：

- openerx 在新任务页增加“新建项目”；UWA 在“远程 → 项目”、项目选择面板和远程操作菜单增加入口。
- 输入项目名称和可选说明，使用已连接电脑的现有权限发送 `project.create`。名称最多 80 个 UTF-16 单元，说明最多 20,000 个，空名称不提交。创建不要求选择模型，也不触发模型调用。
- 电脑端通过已有 ProjectRepository 保存项目；稳定的 `operationId` 使重复命令和同一次创建的重试只产生一个项目。项目写入现有同步 outbox，目录授权仍由电脑端管理。
- 手机收到电脑的成功回执后显示、选择新项目，可以直接发起项目任务。失败时保留表单；UWA 复用持久化命令回执，在响应丢失时查询原回执，不自动重发。创建项目不会清空任务草稿。
- openerx 的创建结果随加密命令回执返回；UWA 同时更新了中央服务 Go 命令校验，保留账户、配对、主机、会话范围和重复命令保护。
