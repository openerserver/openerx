# 移动端思考强度 · 2026-09-16（Asia/Shanghai）

UWA 中央手机端在原有模型面板中增加“思考强度”，按电脑目录发布的档位显示，使用与桌面相同的中文名称。输入栏继续只显示模型图标；更换模型后可直接调整兼容档位，选择随草稿保存。执行中的调整和排队消息不改变强度，下一次独立发送可重新选择。

openerx 与 UWA core 的公共远程协议均增加可选 `thinkingLevel`，用于 `task.start` 和 `session.prompt`。生成帧使用所选值，成功启动后更新会话默认值；历史消息保留原来的强度。UWA 电脑按真实模型能力检查请求，手机不发送模型目录中缺少的档位。

UWA 的模型目录和任务快照通过远程视图版本 3 提供 `thinkingLevels` / `thinkingLevel`。手机与电脑分别声明支持，中心服务协商后传递；旧手机仍接收原来的严格结构，旧电脑不会收到版本 3 请求。新手机连接旧电脑时保留模型选择，并提示更新以启用强度选项。
