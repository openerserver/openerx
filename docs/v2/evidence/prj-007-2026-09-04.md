# PRJ-007 实现证据（2026-09-04）

- 日期：2026-09-04（Asia/Shanghai）
- 状态：`LOCAL PASS WITH DOCUMENTED BASELINE EXCEPTION`
- 证据边界：`DESKTOP PROJECT UI / LOCAL COMPONENT FLOW / NO SYNC OR REMOTE`
- 实施计划：[个人项目功能方案](../26-personal-projects-plan.md)

## 1. 已实现

- 侧栏增加独立 `ProjectSidebar`：活动/含归档切换、项目状态摘要和无目录新建流程；不创建项目仍可直接新建普通对话。
- 新增独立 `ProjectHome`：项目说明、对话、目录连接状态与待重连提示，以及“在此项目中开始对话”入口。
- 新增独立 `ProjectSettings`：名称/说明、侧栏置顶、添加/重连/断开/移除目录、主目录切换、归档与恢复。归档和移除文案明确不会删除磁盘文件。
- 新增 `use-projects` Query hooks 和独立 `projects.css`；大型 `App.tsx` 只增加路由、侧栏插槽和 `projectId` 传递。
- 项目内首页建议和 Composer 首次发送均显式携带 `projectId`；后续轮次继续从 Conversation 持久化归属解析。
- 添加目录可选择只读或可读写；重连时严格沿用逻辑目录原访问级别，避免把只读目录扩大为可写。

## 3. 用户与安全结论

- 普通新对话入口保持原位，项目是可选组织层。
- Renderer 只发送逻辑 ID、revision、访问选择和系统选择器意图，不接触绝对路径。
- 待重连目录明确显示且不会伪装为可用；归档项目不能从 UI 开始新对话。
- 项目说明在界面中明确不能提升工具或目录权限。
