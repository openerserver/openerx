# PRJ-001/002 实现证据（2026-09-04）

- 日期：2026-09-04（Asia/Shanghai）
- 状态：`LOCAL PASS`
- 证据边界：`CONTRACTS / SQLITE V31 / REPOSITORY ONLY`
- 实施计划：[个人项目功能方案](../26-personal-projects-plan.md)

## 1. 本切片交付

1. 新增 Project、ProjectDirectory、设备级 ProjectDirectoryBinding、聚合详情与项目命令 Schema。
2. Conversation 增加可空 `projectId`；同步对象白名单增加 `project` 与 `project_directory`。
3. SQLite 升级至 v31，新增项目、逻辑目录、设备目录绑定表及必要索引和外键。
4. 迁移旧的伪 `source=project` 手动 WorkspaceBinding 为 `user_added`，避免把既有对话目录误认成项目目录。
5. 新增 ProjectRepository，覆盖列表、详情、创建、更新、归档、目录角色切换、连接/断开、删除和对话移动。
6. 所有写操作使用 operationId 幂等，并以 revision 防止并发覆盖；项目绝对路径不进入 Project DTO。
7. ChatRepository 在新建对话时校验项目范围和归档状态，并把 `projectId` 写入对话及同步投影。

## 2. 关键负向证明

| 门禁 | 结果 |
| --- | --- |
| 跨账户读取或修改项目 | Repository 拒绝 |
| 错误 baseRevision 更新 | `PROJECT_REVISION_CONFLICT` |
| 归档项目创建新对话 | `PROJECT_ARCHIVED` |
| 删除唯一主目录但未指定替代目录 | `PROJECT_PRIMARY_DIRECTORY_REQUIRED` |
| 正在运行的对话移入/移出项目 | `PROJECT_MOVE_BLOCKED_BY_ACTIVE_RUN` |
| Binding 或命令携带绝对路径 | 合同中无对应字段 |
| 目录连接状态与 Binding 不一致 | Schema 拒绝 |
| 项目目录 Grant 非项目级或权限不一致 | Repository 拒绝 |
