# PRJ-003 实现证据（2026-09-04）

- 日期：2026-09-04（Asia/Shanghai）
- 状态：`LOCAL PASS WITH UNRELATED BASELINE EXCEPTIONS`
- 证据边界：`PROJECT APP SERVICE / NO DIRECTORY PICKER / NO RENDERER UI`
- 实施计划：[个人项目功能方案](../26-personal-projects-plan.md)

## 1. 本切片交付

1. 新增严格的 ProjectCommandEnvelope 与返回值解析，覆盖项目列表、详情、创建、更新、归档、恢复、目录绑定操作和对话移动。
2. App Service 进程合同接受项目命令，并将其路由到独立 ProjectAppService。
3. ProjectAppService 接入 ProjectRepository，保持 operationId 幂等、revision 冲突和 ownerProfileId 账户隔离。
4. Desktop AppServiceSupervisor 对项目返回值再次按合同解析；畸形返回不能直接进入 Main/Renderer。
5. 修正普通用户手动选择的对话目录来源：新授权写入 `source=user_added`，只允许真实项目继承绑定使用 `source=project`。

## 2. 关键负向证明

| 门禁 | 结果 |
| --- | --- |
| 重复 operationId 创建项目 | 返回首次结果，不产生重复项目 |
| 过期 expectedRevision 更新 | `PROJECT_REVISION_CONFLICT` |
| 另一 ownerProfileId 读取项目 | `PROJECT_NOT_FOUND` |
| 活跃对话移动项目 | `PROJECT_MOVE_BLOCKED_BY_ACTIVE_RUN` |
| App Service 返回畸形项目对象 | Supervisor 返回值解析拒绝 |
| 普通手动目录误标为项目目录 | 回归测试固定为 `user_added` |
