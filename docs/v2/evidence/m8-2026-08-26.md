## Privacy proof

The diagnostic E2E places a unique private Prompt and provider-shaped secret into a real conversation,
forces an App Service restart, previews diagnostics, then exports diagnostics and personal data. The test
asserts that the diagnostic file contains neither canary, secret nor profile path, while the user-requested
personal export contains the canary. Renderer never receives either destination path.

## Performance boundary

The current M8 values are local guardrails from ADR-V2-015, not final Release SLOs. The UI reports each
metric's value, unit, budget and `pass`/`over_budget`/`pending` state. M9 must benchmark cold/warm launch,
idle/active/long-session memory on approved Windows x64 and macOS arm64/x64 machines before replacing
`provisional_local`.
