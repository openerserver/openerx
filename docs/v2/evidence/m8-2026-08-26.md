## Privacy proof

The diagnostic E2E places a unique private Prompt and provider-shaped secret into a real conversation,
forces an App Service restart, previews diagnostics, then exports diagnostics and personal data. The test
asserts that the diagnostic file contains neither canary, secret nor profile path, while the user-requested
personal export contains the canary. Renderer never receives either destination path.

## Real DeepSeek Provider slice

On 2026-08-26 the server-only `.env` configuration was exercised against the official
`https://api.deepseek.com/chat/completions` endpoint. No API key value was printed, persisted in client
state or included in diagnostics.

```bash
npm run test:deepseek -- "只回答：连接成功"
```

The direct service smoke returned `platform/deepseek-v4-flash`, 17 uncached input tokens, 0 cached
input tokens, 2 output tokens and 19 total provider-reported tokens. The same server request produced
one settled CNY Charge with pricing version `deepseek-official-cn-2026-08-26-v1` and a final amount of
1 minor unit.

An authenticated Platform HTTP run then covered email sign-in, billing-term acceptance, automatic
model routing, the real DeepSeek request, UsageRecord persistence, quote/reservation/settlement and
final billing queries. It returned the requested `HTTP链路成功`, 15 uncached input tokens, 3 output
tokens and 18 total tokens; the server exposed one settled 1-minor-unit Charge, left 9,999 minor units
of development quota and had zero active reservation after settlement.

Automated coverage additionally proves fractional Pro cache pricing, provider finish reasons and HTTP
disconnect propagation to the upstream AbortSignal. The current real call is non-streaming; real SSE,
long-running Stop/failure drills and reconciliation against the provider invoice remain external.

The checkpoint run passed 185 source-boundary checks, 267 linted files, all workspace typechecks,
199 automated tests, iOS/Android Expo exports, Electron packaging, darwin arm64/x64 and win32 x64 Fuse
verification, and the complete Chat/Account/Tool/Skill/Beta/Remote E2E sequence. The production audit
passed the `high` threshold; it continues to report 10 moderate `uuid` findings through Expo/xcode. Its
offered force fix is a breaking Expo downgrade, so M8 records rather than silently applies it.
