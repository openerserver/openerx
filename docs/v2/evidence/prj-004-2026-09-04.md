# PRJ-004 实现证据（2026-09-04）

- 日期：2026-09-04（Asia/Shanghai）
- 状态：`LOCAL PASS`
- 证据边界：`DIRECTORY AUTHORIZATION / MAIN PICKER / NO PROJECT UI`
- 实施计划：[个人项目功能方案](../26-personal-projects-plan.md)

## 1. 本切片交付

1. 新增 Renderer 可用的无路径 ProjectBridge，以及只允许 Main/App Service 使用的 `project.directory.choose` privileged schema。
2. Main 对可信主 frame 打开 Electron 系统目录选择器；Renderer 请求合同严格拒绝 `rootPath`。
3. ProjectAppService 通过现有 ToolAppService canonicalize 目录并创建 `conversationId=null`、`allowNetwork=false`、无过期时间的项目级 WorkspaceGrant。
4. 新逻辑目录自动成为首个主目录；后续目录为附加目录。重连沿用已保存的 desiredAccess，不能借请求扩大权限。
5. operationId 重放在创建新 Grant 前返回原结果；绑定失败时补偿撤销新 Grant。
6. 断开或删除 ProjectDirectoryBinding 时，同时撤销源 Grant、派生 Grant 和对应 CapabilityScope。
7. Main、Preload、App Service 和 Supervisor 均使用类型化 Project 命令与返回值解析；项目 DTO 不返回绝对路径。

## 2. 关键负向证明

| 门禁 | 结果 |
| --- | --- |
| Renderer 请求携带 `rootPath` | 严格 Schema 拒绝 |
| 非目录或失效路径 | `PROJECT_DIRECTORY_UNAVAILABLE` |
| stale project revision | 创建 Grant 前拒绝 |
| 重复 operationId | 返回原 Binding，不创建孤儿 Grant |
| 重连请求降低/扩大既有 desiredAccess | 忽略请求值，使用逻辑目录已冻结范围 |
| 断开目录后继续使用 Grant/Scope | Grant 与 CapabilityScope 同时撤销 |
| DTO、IPC 返回绝对路径 | ProjectDirectoryState 严格解析且不含路径字段 |
| Renderer 直接调用 Node/Electron 目录 API | Preload 仅暴露 ProjectBridge，Renderer 继续 sandbox/contextIsolation |
