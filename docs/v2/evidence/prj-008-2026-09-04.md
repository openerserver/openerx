## 3. 用户与安全结论

- 移动对话只修改逻辑归属，不重写历史消息、成果或已完成运行。
- 确认前可见将失去和将继承的目录范围，避免项目切换隐式扩大或缩小下一轮能力。
- 项目目录仍只是当前设备 WorkspaceGrant 的来源标识；项目本身不能授予路径、网络、Browser、Desktop 或 MCP 权限。
- 项目继承目录不能在对话抽屉中被单独撤销，防止 UI 状态与项目配置产生隐式分叉。
