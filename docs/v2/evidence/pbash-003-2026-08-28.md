## 1. 本切片交付

1. 私有 Pi Host IPC 从 v4 升到 v5，新增严格 `pi.tool.progress` 和 `pi.tool.cancel` 合同。
2. AppService 为每个 Tool request 分配从 1 开始的单调进度序号；Pi Host 只接受比已见序号更大的
   pending request 帧，并映射到 Pi ToolDefinition `onUpdate`。
3. Runner 在 stdout/stderr data callback 的到达顺序上构造合并输出。进度与最终日志共用跨 chunk
   sanitizer，不存在“进度未脱敏、最终结果才脱敏”的双轨。
4. sanitizer 去除 CSI/OSC/单字节 ANSI，替换 NUL 等控制字符、授权根、Runner 临时目录和宿主 HOME，
   并遮蔽 Authorization、token/password/secret/api key、OpenAI/GitHub/AWS 常见凭证形态。
5. 无换行单行达到 64 KiB 时整行替换为 `[overlong output line redacted]`，后续内容丢弃到换行；避免
   凭证跨人为截断边界泄露。
6. 最终模型文本取尾部最多 2,000 行且不超过 50 KiB；Runner 已脱敏合并日志最多 2 MiB。
7. AppService 使用现有 FileAppService/ObjectStore 创建 `text/plain` Artifact，ToolResult 的
   `artifacts` 和 `data.logArtifactId` 返回稳定 ID；不向 Pi Host 暴露对象引用或绝对路径。
8. Pi Abort 会发送请求级 `pi.tool.cancel`；AppService 校验 request/generation 绑定后取消 Run。
   timeout、Stop、Pi Host 断连、AppService close 和自然退出仍落到 PBASH-002 的进程组回收。

| 门禁 | 最终结果 |

macOS live canary 使用两次 `printf` 和中间短暂停顿，刻意把 ANSI、真实 `$PWD` 与

```text

```

序列为 `[1]`，序列化进度和 Result 中均不存在真实 workspace 或原始 token。

## 3. 取消与竞态证明

- ToolDefinition 保留 Pi 提供的 `AbortSignal` 和 `onUpdate`；signal 已取消时不发请求。
- 执行中取消会删除 Pi Host pending request、发送 `pi.tool.cancel`，并忽略随后 response/progress。
- AppService 只取消 requestId 与 generationId 同时匹配的活动请求。
- AppService 在 response settled 后不再外发 late progress；Pi Host 同时按 pending map 与 sequence
  拒绝重复、倒序或迟到帧。
- Pi Host 端口断开会拒绝未完成 File/Capability 请求、移除 abort listener 并终止活动 Session。
- AppService 观察到 Pi Host 断连时先投影 `run.cancelling`，调用 Broker `stopAll`，再以
  `PI_HOST_DISCONNECTED` 投影 `run.interrupted`。
- AppService close 仍先 Abort 全部 Generation，再等待 Broker/Runner `stopAll` 后关闭 Repository。

## 5. 启用、回滚与未完成

- 默认仍需同时设置 `OPENERX_BROKERED_BASH_V1=1` 和
  `OPENERX_BROKERED_BASH_RUNNER=macos`；关闭 feature flag 可回到 legacy Shell。
- Pi builtin `bash/read/write/edit` 仍不可达；一个 Generation 不同时暴露产品 Bash 与 legacy Shell。
- 日志 Artifact 只证明当前本地 FileAppService/ObjectStore 路径；尚无跨设备同步、远程下载授权或
  保留策略发布证据。
- PBASH-004 前仍无 changed-path manifest、通用 Undo、diff/conflict 或高隔离审阅后应用。
- 仍无 PTY、长期后台 Session、受控 egress、SecretRef、通用内存/总临时磁盘配额。
- 当前 `/usr/bin/sandbox-exec` 后端 deprecated；没有签名安装、公证/Gatekeeper、未来 macOS、Linux
  或 Windows backend 证据。本检查点保持 `LOCAL ALPHA / LOCAL UNSIGNED / NOT RELEASE`。
