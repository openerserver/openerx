## Security-negative evidence

The strict V2 operation schema rejects extra fields named `selector`, `xpath`, `javascript`, `dom`, `html`,
`path` and `devtoolsCommand`. It also rejects the legacy contract version, `javascript:` navigation, stale
visual IDs, managed-to-system backend downgrade and unredacted password values.

These tests establish input-contract boundaries only. A later Adapter security suite must still prove that
Browser Bridge, Accessibility and managed Chromium implementations cannot leak Cookie/password/history data
or invoke generic script/DevTools paths internally.
