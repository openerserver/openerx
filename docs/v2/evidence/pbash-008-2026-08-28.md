## 1. 当前支持结论

当前没有任何 PBASH 平台达到 Release Supported：

- 当前 macOS 26.5.2 arm64 主机只达到 `Local Alpha`。`/usr/bin/sandbox-exec` 存在，本机 Runner、
  `macos-seatbelt-v1` 和安全合同通过，但制品是 unsigned，且 backend API 已 deprecated。
- macOS x64 只有本地未签名打包产物，没有 x64 主机上的 Runner 矩阵，不能从 arm64 结果外推。
- Linux、WSL2、Windows 没有已实现的等价 backend，状态为 unavailable；不能回退到裸 Bash、旧 Shell
  或 Pi 内置 Bash。

工具中心读取实时 probe 并显示 Runner、backend ID、platform/OS build、sandbox policy、环境、网络和
workspace 状态。Runner probe 失败时显示 unavailable，不投影任何 Shell；关闭 feature flag 才恢复
显式的旧 `openerx_shell` 回滚路径。

## 2. 本机签名门禁

当前主机信息：macOS 26.5.2（25F84）、arm64、Node.js v24.2.0；`/usr/bin/sandbox-exec` 存在。

宽松诊断 `npm run verify:native-signature --workspace @openerx/desktop` 退出 0，但三个现有制品均明确输出
`LOCAL UNSIGNED`：macOS arm64、macOS x64、Windows x64。严格门禁
`npm run verify:d3:macos --workspace @openerx/desktop` 按预期退出 1：

```text
MAC_CODE_SIGNATURE_INVALID:out/UWA-darwin-arm64/UWA.app
```

这证明未签名包不会被严格发布验证误判为可发布。由于本机没有本任务可用的 Developer ID 身份、公证
凭据和分发安装环境，本轮不生成或声称签名证据。

## 3. Fail-closed 矩阵

| 场景 | 结果 |
| --- | --- |
| `platform=linux` | probe unavailable，`BROKERED_BASH_PLATFORM_UNSUPPORTED` |
| `platform=win32` | probe unavailable，`BROKERED_BASH_PLATFORM_UNSUPPORTED` |
| macOS 缺少 `sandbox-exec` | `BROKERED_BASH_SANDBOX_EXEC_MISSING` |
| macOS 缺少 Bash | `BROKERED_BASH_BASH_MISSING` |
| sandbox 强制拒绝自检失败 | `BROKERED_BASH_CAPABILITY_PROBE_FAILED` |
| App Service 已开启 flag，但 probe 失败 | `bash` 与 `openerx_shell` 都不投影，不静默降级 |
| feature flag 关闭 | 只恢复 `openerx_shell` 回滚路径，不改变历史 ToolCall |

PlatformSandbox 合同测试同时覆盖 Linux 与 Windows 的 unavailable 结果；App Service 测试覆盖 backend
probe 失败后的单工具 fail-closed。完整仓库门禁结果记录在本文件第 5 节。

## 4. 后端路线

- macOS：继续把 Seatbelt/`sandbox-exec` 封装为可替换 backend，仅用于当前 Local Alpha。External Beta
  前必须完成维护中替代方案评估、签名/公证安装包、目标 OS/架构矩阵和安装态逃逸回归。
- Linux/WSL2：候选为 bubblewrap 或受维护 helper，但在实现能力探测、进程树、文件、网络、环境、
  change-set 和发行版矩阵前保持 unavailable。
- Windows：需要等价 native sandbox，或另立语义明确的 PowerShell Runner；不能把 WSL/任意 Bash 当作
  已满足 Windows 主机边界。

后端可以使用不同 OS 技术，但都必须实现同一 `PlatformSandboxEngine` 合同、输出 proof，并在能力不足
时 fail-closed。
