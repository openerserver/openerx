- Remote Host Connector 将快照按现有每配对控制器 E2EE 通道发布为 `project.snapshot`；本机项目写入后也会主动发布新的安全快照。

- 主机离线时项目刷新和任务启动不可用；手机 UI 与协议均没有选择目录、提交路径、重连目录、修改读写范围或建立 Grant 的入口。

## 3. 安全结论

- Repository 和严格快照 Schema 双重裁剪；路径 canary、WorkspaceGrant ID 与 ProjectDirectoryBinding ID 均未进入 Remote payload。
- 快照在主机侧生成并通过现有配对密钥分别加密，Relay 只保存/路由密文事件。
- `projectId` 只是新 Conversation 的逻辑归属；实际目录读写仍要求主机当前设备上有效的 WorkspaceGrant，不会因 Remote 选择项目而新增权限。
- 目录为 `reconnect_required` 时手机只能看到状态，不能排队重连或等待未来自动执行目录操作。
