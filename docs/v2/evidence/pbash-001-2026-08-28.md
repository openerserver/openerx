## 1. 本切片交付

1. `brokered_bash_v1` 严格合同：活动/额外 WorkspaceGrant、`read_only` / `workspace_write`、固定
   environment/network/sandbox policy、Bash 命令和 timeout。
2. Pi 私有 IPC 升级为 version 4，`PiPromptFrame.workspace.execution` 只携带可信 App Service 冻结的
   执行上下文。
3. 产品自有 `bash` ToolDefinition 只向模型暴露 `command` 与秒级 `timeout`，保留 Pi 原始
   `piToolCallId` 并生成稳定幂等键。
4. Feature flag `OPENERX_BROKERED_BASH_V1` 默认关闭；开启时 legacy `openerx_shell` / process 工具被
   抑制，多工作区未选择活动根时不回退到旧 Shell。
5. App Service 按 Generation 一次性冻结执行上下文；重复冻结失败且不能改写首次值。
6. deterministic fake adapter 精确比较冻结上下文，执行前重新查询未撤销、未过期且 Conversation
   匹配的 grant，并将不一致映射为稳定 Broker 错误。
7. fake adapter 返回 `executionPerformed=false`、`sideEffectCommitted=false`，不启动进程，不创建测试
   canary 文件。
