## Server-only calculation boundary

The desktop bridge intentionally has no price-quote method. Renderer, Preload, App Service and
Remote clients cannot submit Token counts, usage estimates, rates, quote amounts, pricing snapshots,
balances, ledger entries or payment-success assertions.

The paid model path is:

```text
Pi AgentSession
  -> Platform Model Gateway
  -> server usage budget -> Pricing Service -> immutable PriceQuote/PricingSnapshot
  -> Billing Ledger Service -> funds reservation
  -> upstream model Provider -> provider UsageRecord
  -> Usage Store -> Billing Ledger settlement -> final ChargeRecord
  -> client separately reads final Billing overview/charges/ledger/orders/statements
```

`ChargeRecord` contains the server Usage record and frozen Pricing Snapshot used for settlement.
Unknown fields with a non-zero rate create a pending, zero-deduction Charge and release the
reservation; they are not estimated by the client or silently treated as zero.

Pricing, Billing Ledger, Payment Adapter and Platform HTTP composition. They do not claim real
Alipay/WeChat merchant sandbox settlement, bank/provider refund arrival, tax/legal compliance,
signed packages, or native Windows/macOS payment-flow validation. Those remain release-environment
gates.
