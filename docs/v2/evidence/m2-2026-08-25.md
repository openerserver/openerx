## Implemented request path

```text
React Renderer
  -> typed Preload account/chat/model/usage methods
  -> Electron Main + OS safeStorage credential boundary
  -> account-scoped App Service SQLite + transactional Outbox
  -> Account Sync API (revision/cursor/conflict/tombstone)
  -> isolated Pi Host
  -> Pi AgentSession + native Platform Provider
  -> Platform Model Gateway
  -> provider-reported UsageRecord -> Token Usage Store
```

No upstream Provider API key enters the desktop client. Pi still owns the agent loop; the platform
integration is a Pi-native Provider registered in `ModelRuntime`, not a parallel model adapter or
execution loop.

## Evidence boundary

The Platform Alpha E2E uses a deterministic test-only upstream executor behind the real HTTP Model
Gateway, Usage Store and Pi Provider path. External paid-provider validation, hosted Windows/macOS CI,
native Windows execution, package signing and notarization are release-environment gates and are not
claimed by this local checkpoint.

Remote M2 scope freezes strict device, pairing, signed command, receipt, attention, encrypted product
event, cursor and push-subscription contracts. Mobile apps, Host Connector, Relay, push delivery and
real device pairing remain M6.
