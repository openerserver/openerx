# 数据、网络与工具权限

本说明描述开源默认模式，不替代企业部署方或第三方服务的隐私政策。

## 默认 BYOK 模式

对话、项目、文件索引、Skill、自动化与记忆主要保存在本机 Electron 用户数据目录（通常是 Windows `%APPDATA%/OpenERX` 或 macOS `~/Library/Application Support/OpenERX`，品牌/运行配置会改变路径）。API Key 通过主进程凭据管理保存；安全存储能力取决于操作系统。

本地 SQLite、附件、导出文件、Skill 包和日志不应被视为全部已加密。请使用受控系统账户、磁盘加密和备份；不要上传整个 profile。日志脱敏只能降低泄露风险，提交前仍须人工检查。

模型请求可能包含所选对话上下文、文件提取内容、相关记忆和工具结果。联网搜索访问搜索提供商；网页、MCP 和外部工具访问相应站点。第三方有独立条款、计费及数据保留政策。默认 BYOK 不要求本项目的托管账号，但不意味着完全离线。

## 可选能力

- 记忆可影响后续模型上下文；在设置中检查开关和内容，敏感内容不宜作为长期记忆。
- 自动化可能后台调用模型和工具，请核对任务、权限和费用；退出、休眠、无凭据影响运行。
- 浏览器/桌面操作可能读取页面、窗口或截图，操作前检查目标与授权。
- 第三方 Skill/MCP 是可执行扩展，应检查来源、脚本、权限和网络行为。
- 平台模式、同步、远程控制会改变数据流和部署责任；开发服务不是生产合规承诺。

## Shell 的重要边界

结构化文件工具验证授权、路径穿越和符号链接。Shell 是独立能力，不能把文件工具的保护推定为整个操作系统的保密边界。

macOS Shell 使用系统沙箱限制读写。当前 Windows 外部后端采用 `workspaceWrite` 策略，限制写入和网络，但**不保证无法读取工作区外当前用户可读的文件**。不要用它运行不可信脚本，或在存有敏感文件的账户下将其视为完整读隔离容器。后端缺失不会回退为无沙箱执行。

## 删除与备份

优先使用应用内删除/清理功能。手动备份前应完全退出应用，保证 SQLite 一致性；保留备份直到验证迁移成功。删除本地数据不会删除第三方已收到的内容。复现问题请使用新测试 profile 和合成数据。
